# SmileGrid

A digital art experience built around human presence.

SmileGrid is a modern, gallery-quality single-page website featuring a large immersive digital canvas composed of thousands of small square tiles. Each tile can hold one user-uploaded smiling selfie, forming a growing human mosaic.

## Features

- **Full-viewport Canvas**: Edge-to-edge immersive experience
- **Virtualized Grid**: Performance-optimized rendering of thousands of tiles
- **Smooth Pan & Zoom**: Support for mouse, trackpad, and touch gestures
- **Image Upload**: Easy upload flow with auto-crop to square
- **Beautiful Animations**: Soft fade-in, scale-up, and glow effects
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Persistent Storage**: Tiles are saved locally in the browser

## Technology

- HTML5 / CSS3 / JavaScript (ES6+)
- CSS Custom Properties for theming
- GPU-accelerated transforms for 60fps animations
- LocalStorage for data persistence
- No external dependencies (except Google Fonts)

## Quick Start

1. Open `index.html` in a modern web browser
2. Click "Add your smile" to upload an image
3. Pan and zoom to explore the grid
4. Your images are saved locally in the browser

## Color Palette

- **Background**: Warm off-white (`#FAF8F5`)
- **Accent**: Soft peach (`#FFCBA4`)
- **Text**: Warm dark (`#2D2A26`)

## Keyboard Shortcuts

- `+` / `=` : Zoom in
- `-` : Zoom out
- `0` : Reset zoom
- `Escape` : Close modal
